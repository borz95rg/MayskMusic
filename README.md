# Maysk Music 🎵

**Твоя музыка. Твой стиль. Твои правила.**

Музыкальный плеер для Android (Kotlin + Jetpack Compose + Media3/ExoPlayer) в стиле Premium Dark / Glassmorphism / Neon.
Работает без интернета и регистрации. Обновления приходят прямо в приложение через GitHub Releases.

---

## Как загрузить через GitHub Desktop и получить APK

### 1. Создайте репозиторий
1. Откройте **GitHub Desktop** → `File` → `New repository…`
2. Name: `MayskMusic`, выберите папку → `Create repository`.
3. Скопируйте **всё содержимое** этого архива в созданную папку (вместе со скрытыми папками `.github`, файлами `.gitignore` и `.gitattributes`).
4. В GitHub Desktop появятся файлы → внизу слева напишите `Первая версия` → **Commit to main**.
5. Нажмите **Publish repository**.
   ⚠️ **Снимите галочку «Keep this code private»** — иначе приложение не сможет проверять обновления
   (GitHub не отдаёт релизы приватных репозиториев без токена).

### 2. Добавьте ключ подписи (один раз)
Ключ нужен, чтобы каждое обновление устанавливалось **поверх** старой версии.
Откройте файл `signing-secrets.txt` (он лежит **отдельно** от проекта — не кладите его в репозиторий!).

На сайте GitHub: ваш репозиторий → **Settings** → **Secrets and variables** → **Actions** → **New repository secret**.
Создайте 4 секрета из файла:

| Имя | Что вставить |
|---|---|
| `KEYSTORE_BASE64` | длинную строку |
| `KEYSTORE_PASSWORD` | пароль |
| `KEY_ALIAS` | `maysk` |
| `KEY_PASSWORD` | пароль |

### 3. Запустите сборку
- Вкладка **Actions** → `Build & Release APK` → **Run workflow** (или просто сделайте новый commit + push).
- Сборка идёт ~5–8 минут. Если первый запуск упал из-за отсутствия секретов — после их добавления нажмите **Re-run jobs**.

### 4. Установите на телефон
- На телефоне откройте `github.com/<ваш-логин>/MayskMusic/releases` → скачайте `MayskMusic-1.0.N.apk` → установите
  (Android попросит разрешить установку из браузера — это нормально).

### 5. Как приходят обновления
1. Меняете код → в GitHub Desktop **Commit** → **Push origin**.
2. GitHub Actions сам соберёт новую версию `1.0.(N+1)` и опубликует её в Releases.
3. Приложение при запуске (не чаще раза в 6 часов) или по кнопке **Настройки → Проверить обновления**
   покажет окно «Доступно обновление» → **Обновить** → скачает и откроет установщик.
   Текст коммита показывается как «Что нового».

## Что умеет приложение

**Библиотека**: сканирование всей музыки (MediaStore), треки / альбомы / исполнители / жанры / папки, поиск,
сортировка, массовое выделение (долгое нажатие), «Играть следующим», очередь, удаление файлов с подтверждением,
авто-обновление при появлении новых файлов.

**Папки**: выбор и исключение папок, скрытие служебных (WhatsApp, Telegram, рингтоны, записи звонков…),
фильтр коротких файлов, переименование папок и смена обложек (внутри приложения).

**Плеер**: фоновое воспроизведение, уведомление и экран блокировки, Bluetooth-кнопки, пауза при звонке и при
отключении наушников, shuffle / repeat, перемотка, избранное, очередь с перестановкой, 3 вида плеера
(Обложка / Винил / Минимал), восстановление очереди и позиции после перезапуска, открытие аудиофайлов из
файлового менеджера, gapless-воспроизведение.

**Эквалайзер**: полосы устройства (обычно 5), 12 готовых профилей (Pop, Rock, Rap, Hip-Hop, Jazz, Classical,
Electronic, Vocal, Acoustic, Deep Bass, Podcast, Flat), свои профили, Bass Boost, Virtualizer, усиление громкости.
Эффекты, которые не поддерживает телефон, автоматически блокируются.

**Плейлисты**: создание, переименование, удаление, обложки, порядок треков, сортировка, импорт M3U/M3U8/PLS,
экспорт M3U8. Автоподборки: Часто слушаю, Недавно добавленные, Любимые, Давно не слушал, Для дороги,
Для тренировок / Для сна / Спокойная (по жанрам из тегов файлов).

**Тексты песен**: LRC с подсветкой текущей строки и автопрокруткой, нажатие на строку = перемотка,
размер шрифта, загрузка `.lrc` из файла, ручной ввод. Тексты из интернета не скачиваются.

**Оформление**: 7 тем (Aurora Glass, AMOLED Ultra, Neon Glass, Maysk Dynamic — цвета из обложки,
Modern Minimal, Classic Dark, Light Modern), цвет акцентов и кнопок, прозрачность карточек, скругление, фон,
свечение, размер обложек, сетка, размер шрифта, скорость анимаций, стиль мини-плеера и плеера,
**предпросмотр + кнопка «Применить»**, сохранение своих тем.

**Доступность**: простой режим (крупный текст и кнопки), высокий контраст, отключение анимаций,
поддержка системного масштаба шрифта и TalkBack.

**Ещё**: таймер сна (15–90 мин / до конца трека), история и статистика (только реальные данные),
визуализация (Спектр / Волны / Неоновый круг), поиск дубликатов, виджет рабочего стола,
резервная копия и восстановление (JSON), обновления из GitHub.

### Пока не реализовано (кнопок для этого в приложении нет)
Android Auto, голосовое управление, crossfade и баланс L/R, редактирование тегов, перемещение/копирование файлов,
AI-распознавание треков и подбор обложек из интернета, CUE-файлы, WMA/APE (воспроизводится всё, что умеет
декодер телефона и ExoPlayer: MP3, FLAC, WAV, AAC, M4A, OGG, OPUS; ALAC — если его поддерживает телефон).

## Структура проекта

```
app/src/main/java/com/maysk/music/
├── MayskApp.kt              — контейнер зависимостей
├── MainActivity.kt
├── data/                    — сканирование музыки, плейлисты, настройки (JSON, атомарная запись)
├── playback/                — PlaybackService (Media3), PlayerController, эквалайзер, таймер сна
├── update/                  — проверка и установка обновлений из GitHub Releases
├── widget/                  — виджет рабочего стола
└── ui/                      — тема, компоненты, экраны (Compose)
.github/workflows/build.yml  — сборка и публикация APK
```

Сборка локально (Android Studio): просто откройте папку проекта. Локальная сборка подписывается debug-ключом.
